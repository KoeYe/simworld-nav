Highest-impact findings

Critical

No real-Paris evidence

Synthetic topology, cached views, no physical embodiment, field trial, safety case, or current geographic certificate.

High

Pixels are not yet the benchmark

The only validated condition is designed as a text planning floor. Perception-oriented rungs are unvalidated.

High

Privileged rangefinder leak

Rejected door tools reveal exact metric distance, contrary to the evaluation brief.

High

Public runner is not literal

The documented reference call yields “no order was generated” without a missing reset.

Medium

Units conflict

“Next junction,” route junction counts, block calls, waypoints, and metres do not align for the agent.

Medium

Context is expensive

~1,479 rough system-prompt tokens plus repeated notes, photographs, captions, trail, and map each turn.

What is already good

Typed tools drive both prompt and dispatch; photographs and SVG maps remain distinct; full prompts and ordered media are recorded; every tool costs simulated time; cached/text transitions receive conformance checks; deterministic replay and stress testing are first-class; and the code is unusually candid about unvalidated conditions. These are excellent foundations.

Path to a defensible paper

  1. Remove the exact-distance leak and run adversarial harness tests.
  2. Make one clean-container release command pass tests, readiness, provenance, replay, and dependency preflight.
  3. Validate a perception-essential condition with image removal/shuffle and human/VLM baselines.
  4. Generate hashed result cards with seed lists and confidence intervals.
  5. Publish a compatibility matrix across maps, profiles, conditions, hazards, and runtimes.
  6. Keep real-world Paris deployment as a separate safety-governed program.
